# Tests

Run `npm test` from the repository root. The command builds the BetterDiscord bundle and then runs the Node.js built-in test suite. Coverage includes author ranking, normalization and body omission, per-conversation aggregate storage, privacy sanitization, daily/hourly counts, date ranges, weekly/monthly grouping, exclusions, duplicate handling, partial-coverage status, route selection, rendered-source metadata, cancellation, storage errors, clear/reset, and the generated plugin export.
